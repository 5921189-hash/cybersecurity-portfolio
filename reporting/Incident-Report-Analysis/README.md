# Incident Report Analysis

## 1. Project Overview
This project demonstrates the practical application of the NIST Cybersecurity Framework (CSF) to analyze, contain, and remediate a Distributed Denial of Service (DDoS) attack. It outlines the step-by-step lifecycle of an incident, from initial identification to post-incident recovery and documentation, simulating the core responsibilities of a SOC Analyst.
## 2. Incident Summary

- **Incident Type:** Distributed Denial of Service (DDoS) / ICMP Flooding
- **Impact:** The organization experienced a sudden network outage where servers stopped responding to user requests, compromising the internal network.
- **Duration:** The incident lasted for approximately two hours before full resolution was achieved.

**Full scenrio** you can find [here](./reporting/scenario-for-IRA.md)

## 3. NIST CSF Alignment


| Function     | Analysis                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Govern**   | Organizational governance policies and risk management strategies were established prior to the incident to guide the response team's compliance and reporting requirements.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| **Identify** | *Root Cause Analysis:* The incident response team analyzed the network disruption and determined that normal internal traffic was completely blocked from accessing network resources. This was caused by an incoming flood of ICMP packets.<br><br>*Triage Decision:* To minimize impact, the team decided to immediately shut down non-critical infrastructure and prioritize the restoration of critical network services.                                                                                                                                                                                                                                                                                                                                                                                 |
| **Protect**  | Based on the incident analysis, the cybersecurity team took the following steps to protect the organization from similar incidents in the future:<br><br>*Rate Limiting:* Configured firewalls to limit the rate of incoming ICMP packets, preventing attackers from overloading the servers with excessive requests.  <br><br>*IP Spoofing Protection:* Implemented source IP address verification on the firewall to detect spoofed IP addresses on incoming ICMP packets. The firewall now cross-references external traffic against a database, blocking blacklisted IP addresses and only permitting whitelisted external IPs.  <br><br>*Intrusion Prevention:* Deployed an Intrusion Prevention System (IPS) to actively detect and block suspicious or malicious traffic before it enters the network. |
| **Detect**   | To detect threats early, the following steps were suggested:<br><br>*Traffic Monitoring:* Utilizing network monitoring software to establish baseline patterns, detect abnormal traffic spikes, and enable prompt incident response.  <br><br>*Signature-Based Detection:* Integrating additional security appliances, such as an Intrusion Detection System (IDS), to inspect and identify suspicious characteristics within ICMP traffic.                                                                                                                                                                                                                                                                                                                                                                   |
| **Respond**  | *Internal Communications:* The incident response team formally notified corporate management of the ongoing incident. Concurrently, the technical support department notified internal employees regarding the network disruption.  <br><br>*Continuous Improvement:* To prevent future DoS/DDoS exploits, the team initiated an analysis of additional infrastructure vulnerabilities and updated the baseline security instructions.  <br><br>*External Escalation:* Prepared documentation to notify government authorities of the incident to facilitate a formal external investigation.                                                                                                                                                                                                                 |
| **Recover**  | *Service Restoration:* The technical team initiated the process to restore secure access to the compromised servers.  <br><br>*Business Continuity:* Access is being gradually re-opened to employees in a phased manner to ensure stability as they return to their daily operational tasks.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |


## 4. Skills And Tools Demonstrated

- **Frameworks:** NIST Cybersecurity Framework (CSF)
- **Network Security:** Firewall Configuration (Rate Limiting, IP Whitelisting/Blacklisting), Traffic Analysis  
- **Security Operations (SecOps):** Incident Response Lifecycle, IDS/IPS Deployment Strategies, Vulnerability Remediation Planning
